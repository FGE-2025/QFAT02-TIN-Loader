about=- Imports common engineering terrain surfaces for fast review and QA.
    - Supports 12d (.12da/.12daz), auto-detected .tin, DXF 3DFACE, and LandXML surfaces.
    - Opens supported terrain files as QGIS mesh layers where possible.
    - Converts supported surfaces to 2DM for editing and model-input workflows.
    - Supports drag-and-drop onto the map canvas or layer panel / TOC.
    - Includes options for TIN handling, overwrite behaviour, 12d hidden triangles, and import summaries.

    This tool is part of QFAT (QGIS Flood Analysis Toolkit) — a set of focused QGIS utilities designed to support flood modelling workflows (e.g., TUFLOW, HEC-RAS), hydraulic QA, and rapid engineering checks.
