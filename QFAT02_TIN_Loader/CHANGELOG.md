# Changelog

## v2.2.27

Consolidated update from v2.1.0.

- Added DXF 3DFACE support.
- Added LandXML surface import.
- Added `.12daz` support.
- Added automatic 12d encoding detection and UTF-8 conversion for parsing.
- Added `.tin` format auto-detection.
- Added drag-and-drop support for the map canvas and layer panel / TOC.
- Added Settings dialog with configurable import behaviour.
- Added write-permission warning with option to save generated `.tin` / `.2dm` outputs to the QGIS temporary folder.
- Improved DXF drag-and-drop, including Open as TIN / Mesh, Open as 2DM, and Open normally in QGIS.
- Regrouped toolbar and plugin menu by file type.
- Improved UI layout, icons, and About section.
- Renamed the 12d full TIN setting to: Skip hidden 12d triangles in full TIN.

## v2.1.0

- Initial QFAT02 TIN Loader release.
- Supported `.12da`, SMS/XMS `.tin`, and editable 2DM workflows.
